Cấu hình chế độ API AI và khóa API cho hệ thống phân tích lừa đảo CyberÚ.

Sử dụng API cá nhân

Người dùng tự tải lên Gemini API Key cá nhân. Khi chạy phân tích, hệ thống sẽ ưu tiên sử dụng API Key này.

Sử dụng API có sẵn (Hệ thống CyberÚ)

Sử dụng API được thiết lập sẵn. Hệ thống sẽ luân phiên linh hoạt sử dụng các mô hình AI:

gemini-3.8-flash gemini-3.7-flash gemini-3.5-flash-lite gemini-3.1-pro-preview gemini-3.1-flash-lite gemini-pro-latest

Tự động chọn mô hình phù hợp nhất theo loại phân tích được lựa chọn ở tab Trình phân tích lừa đảo.

Cấu Hình Google Gemini API Key

Nhập Google Gemini API Key cá nhân của bạn để sử dụng các mô hình AI trực tiếp.
